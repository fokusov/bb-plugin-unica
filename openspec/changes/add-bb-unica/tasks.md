## 1. Базовый контракт

- [x] 1.1 Зафиксировать публичные схемы, CLI, политики и DAP действующей реализации. Собрать таблицу переноса и проверить лицензии заимствований.
- [x] 1.2 Проверить на SDK 0.6.157 решение для обнаружения окружения, регистрации инструментов и конфликта владельцев. При смене SDK повторить проверку.

## 2. Интеграция

- [x] 2.1 Вынести мост, проверку версии, подготовку рантайма и CLI. Подключить навыки и справочники в поддерживаемом профиле без дублирования.
- [x] 2.2 Перенести политику, подтверждения, адресацию worktree и управление задачами. Сквозная проверка отложенной операции входит в пункт 3.2.
- [x] 2.3 Перенести DAP и проверить два маршрута на отдельном тестовом контуре с чистым завершением процессов.

## 3. Приёмка

- [x] 3.1 Собрать плагин и установить его из тестового Git-тега. Проверить вызовы в чистом профиле с реальным рантаймом.
- [x] 3.2 Получить реальный `taskId` Unica и прочитать результат отложенной операции. В рабочем BB получены отложенный результат с диагностикой и успешный план `make` с `dryRun: true`. [Протокол](../../../docs/verification-3.2.md)
- [x] 3.3 Вместе с совместимой локальной сборкой `1c-properties` прогнать переход и откат. Сохранить результаты и таблицу совместимости.
- [x] 3.4 Проверить свежий агентский поток с реальным рантаймом. В двух новых тредах настольного BB на Windows вызовы через `unica_tools` и `unica_call` прочитали разные версии одного модуля из своих worktree.
